# Sistema de ventas online de ropa - H&M

Proyecto académico de una aplicación de escritorio para apoyar la gestión de ventas de ropa, productos, clientes e inventario.

**Descripción del proyecto**

Este proyecto representa el proceso de venta online de prendas de vestir, desde la consulta de productos y la selección de variantes hasta el registro de la venta y la gestión del inventario. La aplicación está desarrollada en Java Swing y utiliza una base de datos MySQL.

El trabajo también analiza el proceso actual de venta, identifica problemas relacionados con el stock, los pagos, la preparación de pedidos y el seguimiento, y plantea una propuesta de mejora.

**Objetivo**

Desarrollar un prototipo que permita representar las funciones principales del proceso de venta de ropa y apoyar la organización de la información de productos, clientes, ventas e inventario.

**Funciones contempladas**

- Consultar y gestionar productos de ropa.
- Registrar y consultar información de clientes.
- Controlar productos e inventario.
- Registrar ventas y pedidos.
- Organizar la información mediante una base de datos MySQL.


**Tecnologías utilizadas**

- Java 17
- Java Swing
- Apache Maven
- MySQL 8
- JDBC
- Apache NetBeans como entorno de desarrollo


**Contenido del repositorio**

- `pom.xml`: configuración del proyecto Maven.
- `src/main/java/com/hm/ventas`: código fuente de la aplicación.
- `sql/`: scripts para crear o configurar la base de datos.
- `LEEME.txt`: información adicional del proyecto.

**Requisitos para ejecutar el proyecto**

- Tener instalado JDK 17.
- Tener instalado MySQL 8.
- Contar con Apache NetBeans u otro entorno compatible con proyectos Maven.
- Descargar el proyecto y el script SQL de este repositorio.

**Instalación y ejecución**

1. Descargar o clonar este repositorio.
2. Abrir MySQL Workbench.
3. Abrir y ejecutar el script de instalación ubicado en la carpeta `sql/`.
4. Abrir en NetBeans la carpeta raíz del proyecto, donde se encuentra el archivo `pom.xml`.
5. Configurar la conexión a MySQL con las credenciales de la instalación local.
6. Ejecutar el proyecto desde NetBeans.

**Alcance y estado**

El repositorio contiene un prototipo académico de escritorio. La disponibilidad de las funciones depende de la versión incluida en el proyecto. Los pagos y las entregas deben considerarse simulados si no están conectados a servicios reales.

**Seguridad**

No subir contraseñas, claves de conexión, datos personales ni información real de clientes. Utilizar únicamente datos de prueba.
